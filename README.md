# E-Commerce Selenium Automation

## Project Overview

This project is an automated testing framework developed using Java, Selenium WebDriver, TestNG, and Maven.

The project automates important functionalities of the SauceDemo e-commerce website.

## Website

https://www.saucedemo.com/

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Chrome Browser
- Git
- GitHub

## Design Pattern

Page Object Model (POM)

## Features Automated

### Login
- Valid login
- Invalid login

### Products
- Verify product count
- Add product to cart
- Sort products

### Cart
- Verify cart
- Add multiple products

## How to Run

### Step 1

Clone the repository.

### Step 2

Open the project in IntelliJ IDEA or Eclipse.

### Step 3

Make sure Java and Maven are installed.

### Step 4

Run:

mvn clean test
